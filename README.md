# 方块突击 🎮

网页版 3D 第一人称方块枪战小游戏。前端 Three.js（单文件），后端 Node.js + Socket.IO。
无需安装任何客户端，浏览器打开就能玩，手机平板也能直接玩。

## ✨ 功能

- **单机打怪**：开局 6 只怪物，之后不管杀不杀，自动越刷越快（最快 1.5 秒一只，上限 30 只）
- **双人合作打怪**：怪物由服务器统一托管，两人看到同一批怪；倒地 5 秒可被队友救起（复活血量 10）
- **双人对战**：150 小图双人 PvP，同样有怪物刷新，边打人边防怪
- **局域网联机**：同一 WiFi 下手机扫码 / 输地址直接进
- **远程联机**：基于 cloudflared 公网隧道，不同网络（4G/5G）也能连
- **手机/平板**：自动启用虚拟摇杆 + 虚拟开火按钮，可自定义按键位置/大小/灵敏度；PWA 支持添加到主屏幕
- **地图随机**：每局障碍物、楼房位置/大小/颜色随机；可进楼爬楼梯上到楼顶打高处
- **拾取系统**：地图上随机刷弹药箱（步枪弹/狙击弹）和医疗包

## 🚀 快速开始

需要安装 [Node.js](https://nodejs.org)（建议 18 以上）。

```bash
# 1. 进入项目目录
cd 方块突击

# 2. 安装依赖（只需第一次）
npm install ws qrcode-terminal

# 3. 启动服务器
node server.js
```

浏览器打开 **http://localhost:8080** 开始玩。

> 第一次启动如果 Windows 弹防火墙询问，请勾选「专用网络」并点允许，否则朋友连不上。

## 🎯 操作说明

| 操作 | 按键 |
|---|---|
| 移动 | WASD |
| 转视角 | 鼠标 |
| 开枪 | 左键 |
| 换弹 | R |
| 跳跃 | 空格（可在设置里改成 C） |

手机端进入游戏后自动显示虚拟摇杆和按钮，可在设置里调整位置、大小和灵敏度。

## 📦 Windows 一键启动器

用 C# 写的自包含启动器（源码见 `launcher.cs`）：

1. 双击 exe 启动
2. 自动把游戏文件解压到 `%LOCALAPPDATA%\方块突击`
3. 点 **「局域网联机」** 或 **「远程联机」** 按钮
4. 二维码自动生成、链接自动复制到剪贴板，发给朋友即可开玩

## 🤝 联机方式

- **局域网**：朋友连同一个 WiFi，用手机相机扫码或手动输入地址
- **远程**：点「远程联机」，等几秒出现 `https://xxx.trycloudflare.com` 公网网址，发给朋友，**任何网络都能打开**

## 📁 文件说明

| 文件 | 说明 |
|---|---|
| `枪战.HTML` | 游戏前端（Three.js 单文件，含全部玩法） |
| `server.js` | Socket.IO 联机服务器（房间/合作/对战/刷怪/拾取） |
| `launcher.cs` | Windows 自包含启动器源码（C# WinForms） |
| `qrlan.js` | 局域网地址二维码 + 剪贴板脚本 |
| `remote-run.js` | 远程联机一键启动（cloudflared 隧道）脚本 |
| `showqr.js` | 通用二维码 / 剪贴板小工具 |
| `mobile/` | 手机主机版（Termux 环境）启动脚本 |
| `manifest.json` / `sw.js` | PWA 离线缓存支持 |

## ⚠️ 注意事项

- 本仓库只包含**源码**，不含大体积二进制（`node.exe`、`cloudflared.exe`、打包后的 `.exe`），请自行下载对应工具或使用打包好的启动器。
- `cloudflared` 账号级隧道无稳定保障，仅适合朋友间联机测试。
